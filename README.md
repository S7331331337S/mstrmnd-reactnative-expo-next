# mstrmnd-reactnative-expo-next

A monorepo containing the MSTRMND app for both web and mobile.

## Structure

```
├── web/      # Next.js web app (shadcn/base-ui, Tailwind v4)
└── mobile/   # Expo React Native app (NativeWind, Expo Router)
```

## Getting started

**Web** — from the `web/` directory:
```bash
npm install
npm run dev
```

**Mobile** — from the `mobile/` directory:
```bash
npm install
npm run ios   # or android / web
```
